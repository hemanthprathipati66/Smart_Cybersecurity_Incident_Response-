# Smart Cybersecurity Incident Response System

A Python-based cybersecurity incident management system that demonstrates Object-Oriented Programming (OOP), automated threat detection, incident response, JSON persistence, reporting, statistics, exception handling, and unit testing.

## Project Overview

The Smart Cybersecurity Incident Response System is a defensive cybersecurity project designed to simulate the process of detecting and responding to security incidents.

The system can:

- Detect suspicious security events
- Create cybersecurity incidents automatically
- Classify incident severity
- Manage incident status
- Apply automated response actions
- Store incidents using JSON
- Generate incident reports
- Generate incident statistics
- Handle custom security exceptions
- Run automated unit tests
